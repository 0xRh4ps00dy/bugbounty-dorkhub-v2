🚀 Browser Extensions

Enhance your bug bounty workflow with our specialized Chrome extensions designed to streamline your reconnaissance process.

🔗

BugBounty Dorkhub Extension

Why you need it: Manually opening dozens of dork searches is time-consuming and browsers block multiple pop-ups. This extension allows you to launch all dorks from an entire category with a single click, bypassing pop-up blockers and saving you hours of repetitive work.

  • ✓ Open all category dorks at once
  • ✓ Bypass browser pop-up blockers
  • ✓ Auto-mark as completed
  • ✓ Save progress in localStorage
📋

Search URL Extractor

Why you need it: After running dork searches, you need to collect and organize results efficiently. This extension automatically extracts all URLs from Google and DuckDuckGo search results, eliminating tedious manual copying and allowing you to quickly export targets for further analysis.

  • ✓ Auto-extract URLs from search results
  • ✓ Filter ads and internal links
  • ✓ Copy to clipboard instantly
  • ✓ Download as TXT file

📦 Extension Installation Guide

1 BugBounty Dorkhub Extension (Chrome)

  1. Open Chrome and navigate to chrome://extensions/
  2. Enable "Developer mode" in the top-right corner
  3. Click "Load unpacked" button
  4. Select the folder: chrome-extension/ from this project
  5. You'll see a new "Open Category" button in each category
  6. Enter your target domain and click the green button to open all dorks!

2 Search URL Extractor (Chrome)

  1. Open Chrome and navigate to chrome://extensions/
  2. Enable "Developer mode" in the top-right corner
  3. Click "Load unpacked" button
  4. Select the folder: ddg-url-extractor/ from this project
  5. Visit Google or DuckDuckGo and perform any search
  6. Click the orange "📋" button that appears or open de Extension
  7. Copy or download all extracted URLs with one click!
💡 Pro Tip: Install both extensions for the complete workflow - use the Dorkhub Extension to run searches, then use the URL Extractor to collect results from Google or DuckDuckGo pages.

🦊 Firefox: Use about:debugging#/runtime/this-firefox and load firefox-extension-dorkhub/manifest.json (helper) or firefox-ddg-url-extractor/manifest.json (extractor).
